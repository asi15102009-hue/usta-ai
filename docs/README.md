# УСТА АИ (Project Atlas) — v0.1

Курулуш тармагындагы инженердик эсептөөлөрдү автоматташтыруучу программа.
Фундамент, дубал жана чатыр үчүн материал көлөмүн эсептейт жана PDF отчет түзөт.

Толук талаптар: [`SRS.md`](./SRS.md) · Архитектура: [`Architecture.md`](./Architecture.md) ·
Пландар: [`Roadmap.md`](./Roadmap.md)

## v0.1 эмнени камтыйт

- 🧱 **Фундамент** — бетон, цемент, кум, шагыл, арматура, опалубка
- 🧱 **Дубал** — материал саны, раствор/клей, сетка (кирпич/пескоблок/пеноблок/газоблок/шлакоблок)
- 🏠 **Чатыр** — жабуу материалы, стропила, конек, желоб, гидро/пароизоляция
- 📄 **PDF отчет** — кыргызча же орусча, объект аты/дата/параметрлер/натыйжалар менен
- ✅ Валидация жана түшүнүктүү ката билдирүүлөрү
- 🌐 Кыргызча / Орусча интерфейс которгуч

**v0.1де жок:** каттоо/кирүү (Guest/Google/Email), долбоорлорду сактоо — бул талап боюнча
атайын кийинки версияга калтырылды.

## Ишке киргизүү

```bash
cd backend
python3 -m venv venv && source venv/bin/activate   # каалаган болсо
pip install -r requirements.txt
python app.py
```

Андан кийин браузерде ач: **http://127.0.0.1:5000**

Backend бир эле учурда API'ни жана `frontend/` папкасын тейлейт — өзүнчө сервер керек эмес.

## Долбоордун түзүлүшү

usta-ai/
├── assets/ # PDF үчүн шрифттер (DejaVuSans — кирилл/кыргыз тамгалары)
├── backend/ # Flask API + эсептөө логикасы + PDF генерациясы
├── frontend/ # HTML/CSS/JS интерфейс
├── docs/ # SRS, архитектура, роадмап
└── git-lessons/ # Git менен иштөө боюнча кыскача колдонмо


## Технологиялар

- **Backend:** Python 3, Flask, ReportLab (PDF)
- **Frontend:** Vanilla HTML/CSS/JS (framework жок)
- **Тилдер:** Кыргызча (негизги), Орусча

## Эскертүү

Бардык эсептөөлөр орточо нормативдик көрсөткүчтөргө негизделген (SRS NFR-005). Так курулуш
долбоору үчүн бул программа инженердин ордун алмаштырбайт (SRS бөлүм 3).
